# Cockpit

Un ecran de decizie pentru memecoins pe Solana, cu frână. Regulile tale (lichiditate, holderi, trade-uri pe zi, risc zilnic, cooldown după pierderi, teză obligatorie) controlează direct ce poți apăsa.

- Date reale, doar citire: DexScreener și GeckoTerminal.
- Execuție **doar pe hârtie**. Nu conectează niciun portofel și nu cere chei.
- Totul rămâne în browserul tău (localStorage).

```bash
npm install
npm run dev    # http://localhost:5190
npm test
npm run deploy # publică pe GitHub Pages
```

Live: https://cojocariuemilian73.github.io/cockpit/
